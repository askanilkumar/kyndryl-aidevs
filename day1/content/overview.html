How a request travels, end to end

Solid line: your request. Dashed line: monitoring. If Kimi fails, the gateway retries and then calls DeepSeek, and you do not have to change anything.

Why a gateway?

One address, one key per person, one place to switch models, track cost and survive an outage.

Why no cloud keys on VMs?

The real provider keys live only on the gateway. A leaked VM key can be switched off in seconds without touching anything else.

Why Grafana?

You can see the failure while it happens: a model turning red, a VM down, a slow response.

New to this? Start here.LiteLLM is a switchboard for AI models. Your tools talk to one address; the switchboard decides which real model answers.

Four words to know

GatewayThe single door every request goes through
Virtual keyYour personal pass (starts with sk-). It works only at the gateway and can have limits
Model name (alias)A friendly name like kimi-k2.7-code. The gateway maps it to the real model behind it
FallbackPlan B: if model A fails, try model B automatically

What happens when you press Enter

1
Your tool sends the question and your key to the gateway.
2
The gateway checks: is this key valid? Allowed to use this model?
3
It forwards the call to the real model with its own secret key.
4
The answer comes back. The gateway notes tokens and cost.

Try it (PowerShell on your VM, 3 minutes)

Open a new PowerShell window (so it sees your key). Your key is already set on this VM as LITELLM_API_KEY.

1. Which models can I use?
PowerShell
Invoke-RestMethod -Uri http://172.16.0.6:4000/v1/models -Headers @{Authorization="Bearer $env:LITELLM_API_KEY"} | % { $_.data.id }
2. Ask a model a question
PowerShell
$body = @{model="kimi-k2.7-code"; messages=@(@{role="user"; content="Explain an API gateway in one sentence"}); max_tokens=300} | ConvertTo-Json -Depth 5
Invoke-RestMethod -Uri http://172.16.0.6:4000/v1/chat/completions -Method Post -Headers @{Authorization="Bearer $env:LITELLM_API_KEY"} -ContentType "application/json" -Body $body | % { $_.choices[0].message.content }
3. Switch the model, change nothing else

Edit model= in step 2 to deepseek-v4.1-flash and run it again. Same address, same key, different model. That is the whole point of a gateway.

4. Break it on purpose

Change the model to no-such-model. Read the error. Which part of the system said no: your tool, the gateway, or the model?
