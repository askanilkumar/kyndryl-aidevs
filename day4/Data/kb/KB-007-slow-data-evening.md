# KB-007 — Slow 4G data in the evening

In most Indian metros 4G cell congestion is heaviest between 19:00 and 23:00. If the user reports slow data only in this window, this is usually normal.

Suggested steps:
1. Confirm 4G and not 2G/3G in the status bar.
2. Try switching to 5G if the device supports it.
3. If speeds remain under 1 Mbps for more than two days, raise a P3 ticket.
