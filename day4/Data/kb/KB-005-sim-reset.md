# KB-005 — Lost phone / SIM reset

If a device is lost or stolen the user can request a SIM reset to deactivate the old SIM and re-issue a new one.

Agent action: call tool `reset_sim(user_id)` after confirming identity.

The user must:
1. Insert the new SIM in a new or wiped device.
2. Restart the device.
3. Wait up to 10 minutes for the network to recognise the new SIM.

Account PINs and MyNet passwords are not changed by a SIM reset. Advise the user to also change the MyNet password from the website.
