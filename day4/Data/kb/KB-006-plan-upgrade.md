# KB-006 — Upgrading from Gold to Platinum

Any user can upgrade mid-cycle. The new plan is pro-rated from the day of upgrade.

Platinum adds:
- Unlimited 5G data (fair-use 500 GB)
- Free roaming in SAARC countries
- Priority support line

Do NOT upgrade a Prepaid user — Prepaid cannot be converted directly; the user must raise a port-in request to Postpaid first.
