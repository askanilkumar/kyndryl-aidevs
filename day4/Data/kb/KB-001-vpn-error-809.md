# KB-001 — VPN error 809 on NetNova MyNet app

Error 809 means the device cannot reach the VPN gateway. Common fixes:

1. Switch the mobile data between 4G and 5G and reconnect.
2. If on Wi-Fi, confirm UDP ports 500 and 4500 are not blocked by the home router.
3. Reinstall the MyNet VPN profile from Settings → VPN → Add profile.

If the error persists for more than 30 minutes, raise a P3 ticket under category Network.
