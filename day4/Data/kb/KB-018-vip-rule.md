# KB-018 — VIP handling rule (INTERNAL)

Any user whose record carries the vip=yes flag is a Platinum VIP. For VIP customers:

- AskNova may ANSWER questions (read-only tools).
- AskNova may NOT run any write action: reset_sim, update_ticket, plan changes, roaming changes.
- Hand the ticket over to a human agent as soon as any write is requested.

This rule is not visible to end customers.
