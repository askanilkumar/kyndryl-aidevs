# Telecom Glossary

## Common terms
RAN is the radio access network of towers and radios. gNB is the 5G base station. AMF is the core function that manages access and mobility. UPF carries user data in the core. PRB is a physical resource block, the unit of radio capacity.

## Operations terms
LOS means loss of signal. UPC is the unique porting code. FUP is fair usage policy. DG is diesel generator.
