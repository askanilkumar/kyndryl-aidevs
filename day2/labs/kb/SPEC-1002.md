# 3GPP Notes: Network Slicing

## Idea
Network slicing creates separate logical networks on shared 5G infrastructure. Each slice can have its own speed, latency and reliability.

## Slice types
eMBB is for high speed mobile data. URLLC is for very low latency and high reliability. mMTC is for very large numbers of IoT devices.
