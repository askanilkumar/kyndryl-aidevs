# Port-out (MNP) Rules

## How to request
Send SMS PORT followed by your mobile number to 1900. You receive a UPC code.

## Validity and conditions
The UPC code is valid for 4 days. Postpaid customers must clear all dues before porting out. Prepaid customers must have used the number for at least 90 days.
