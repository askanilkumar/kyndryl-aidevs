# Runbook: Sector Congestion

## Trigger
Start this runbook when PRB utilisation is above 85 percent for 3 busy hours in a row on the same sector.

## Actions
First try load balancing between carriers. If congestion continues for 7 days, raise a capacity request to add a carrier.
