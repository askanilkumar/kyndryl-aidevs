Memory and tools for the NetNova support bot. One app. One command. Everything inside it.

The big picture

Day 1 gave us a model. Day 2 gave it knowledge (RAG). Day 3 gives it a memory and the power to act, safely.

Remember (Lab 1) → Choose tools (Lab 2) → Stay safe (Lab 3) → Break it and fix it (Challenge)

Start here 5 min

Open a terminal in the lab folder.
cd day3\labs
Check the setup (expect Agent test: ok).
python check_setup.py
Start the app. This is the only app you need.
python -m streamlit run studio_app.py
It opens at http://localhost:8501. Stop it with Ctrl+C.
Open the first tab: "0 · Journey". Click the steps on the left, in order. Press ▶ Run to run each script. Click Show the code to read it.

Failure Lab hints (open one at a time)

F1 · Two customers see each other's chat
Hint 1

Look at _key(). What does the key contain? Compare it with agentlib/memory.py → chat_key().

Hint 2

Two users with the same session name get the same key. Which piece of information tells them apart?

Hint 3

The key must have three parts: a label, the user id and the session name.

F2 · The history grows forever
Hint 1

Redis has a command that keeps only the last N items of a list, and another that sets an expiry. Look at memory.add_message().

Hint 2

The commands are LTRIM and EXPIRE. The numbers live in agentlib/config.py.

Hint 3

After rpush: trim to -config.MAX_MESSAGES through -1, then expire the key after config.TTL_SHORT seconds.

F3 · The agent loops forever
Hint 1

What stops a while True loop? Look at how lab3b_limits.py ended the loop.

Hint 2

Count the steps. The limit is config.MAX_STEPS. What should the function return when the limit is hit?

Hint 3

Loop while steps < limit. After the loop return a dict with stop_reason set to 'max_steps' and a polite answer for the customer.

F4 · One flaky tool call kills the answer (stretch)
Hint 1

A single attempt fails on the first timeout. How many attempts would be sensible for a read?

Hint 2

Try up to 3 times, pause a little between attempts, and re-raise the last error if all fail.

Hint 3

A for loop of 3 attempts with try / except and time.sleep(). Never retry forever.

F5 · A ticket note gives orders (stretch)
Hint 1

Text that comes from a tool or a document is data. Is there a helper in agentlib/guard.py that looks for orders?

Hint 2

guard.scan_injection(text) returns the patterns it found. Use it before the text goes into the prompt.

Hint 3

If it finds something, replace the note with a short placeholder and return True as the second value. Otherwise leave the note unchanged.
