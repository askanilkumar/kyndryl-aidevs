Lab 1 — the MCP server (40 min)

What you are building

One HTTP server exposes 4 tools. The agent (and you) talk to it through two endpoints: GET /tools/list and POST /tools/call.

Steps

  1. Open mcp_server.py. Read the TOOLS list — four entries, each with name, description, risk, args.
  2. In the Streamlit app, open Tab 1 · MCP Server. You should see "MCP server is UP" and the 4 tools.
  3. Call each tool once from the tab:
    ToolArgs to try
    kb_search{"query":"escalation","role":"engineer"}
    ticket_lookup{"incident_id":"INC-5102"}
    tower_status{"tower_id":"TWR-CHN-11"}
    plan_change{"customer_id":"C-1002","new_plan_id":"PLAN-202"}
  4. Open http://127.0.0.1:8765/tools/list in a browser tab. Same output. MCP is just HTTP with a shape.
What you just learned: MCP decouples the agent from the tools. The agent only knows an endpoint and a tool name — same wire for anything.

Lab 2 — Agent + Registry (RBAC) (40 min)

Files to look at (in order)

  1. registry.json — one tool per row: risk, allowed_roles, requires_approval. This is your policy.
  2. rbac.py — 10 lines: can_call(role, tool), requires_approval(tool), audit(...).
  3. agent.py — LangGraph graph: plan → guard → execute. The guard is where RBAC lives.

Run these 4 presets in Tab 2

The agent trace shows each tool call. The denial lines are what you'd ship to compliance.

Lab 3 — Approvals + Audit (30 min)

  1. In Tab 2, as supervisor, run: "Change customer C-1002 to PLAN-202 as goodwill compensation for the INC-5102 outage."
  2. The trace shows the agent pauses before plan_change. Switch to Tab 3 · Approvals + Audit.
  3. Read the pending approval card. Decide Approve or Reject. Watch what happens in the audit log below.
  4. Scroll the audit log. Every event is one row: proposed, approved/rejected, executed, denied, error.
  5. Download audit.jsonl. This is what your SOC team wants.
What you just learned: HITL is not a dialog — it is a pause point in the graph with an audit record on either side. The policy decides which tools pause; the human decides each call.
